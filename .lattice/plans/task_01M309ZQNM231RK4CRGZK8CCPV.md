# Plan (delegator-pq12, 2026-09-26)

Base: origin/main @ ed32240 (#21 merged; branch fast-forwarded, upstream unset). PR against main.

## Shape

One question record -> `bake(question)` (Python, the pipeline) -> a JSON literal baked into one HTML file -> `static.js` builds the wall's frames from it in the browser, the same shape `view::wall` sends -> `PopQuiz.Wall.html()` (PQ-7's pure renderer, unchanged) draws them. So the static wall is the live wall's renderer fed by a local state object, never a second design (SPEC §12).

## Files

1. `web/wall/static.js` (new). `PQ.Static`:
   - `frame(bake, state)` -> a wall frame for `{phase, at}`, a line-for-line mirror of `room/src/view.rs` `sealed::wall` / `revealed::wall`, strings from copy.js via `PQ.t`. No `join` (the join strip is omitted, SPEC §12); `code` omitted. `work` holds the walk (steps 0..M-2, `stdout` rows removed, as `answers::load` does) and clamps `at` to 0..M-2; `reveal` enters at M-1 and clamps to 0..M-1. Split/reveal counts: `bake.room` is absent in the real file (no phones), so totals are zero and the split renders §4.4's `0 · 0%` bars and the reveal §4.5's *Nobody read it another way.* (the room's own rule for "nobody answered"); the `‹answered› of ‹present›` line is a statement about phones in a room, so with no room it is omitted, like the join strip. A test-only `counts` argument lets the parity test feed the fixture's totals.
   - `next(state)`, `back(state)`, `step(state, ±1)` — the driver as pure transitions over `idle→live→closed→split→work→reveal→released`. `Space` next phase (entering `work` at 0, `reveal` at M-1), `Esc` back a phase (entering the previous phase at its entry step), `←`/`→` step only inside `work`/`reveal`, no-ops elsewhere, never past the bounds. At `released` Space does nothing; at `idle` Esc does nothing.
   - `boot()` — reads the baked literal from `<script type="application/json" id="pq-static">`, mounts via `PQ.Wall.mount` (no `onFit`: there is no room to tell), shows the idle frame, binds keydown. In `idle` the strip shows the §11 *Static fallback* key legend (`static_*` keys in copy.js), where the join strip was.
2. `web/wall/wall.js`: two guards only — `live`/`split`/`reveal` render the strip only when the frame carries `join`/`split.line`; auto-`boot()` skips a wrap marked `data-mode="static"`; `html(frame, {strip})` accepts an optional replacement strip string (used for the legend). Live behaviour unchanged; every existing wall test stays green.
3. `web/wall/qr.js`: its one comment URL written without the scheme, so the built file carries no `https://` outside the baked record (comment-only change).
4. `web/wall/fixtures/q3-static.json` (new, GENERATED by `python -m popquiz.fallback --bake q3`, held equal by a pipeline test): `bake(q3)`.
5. `pipeline/src/popquiz/fallback.py` (new, one module):
   - `bake(question, *, home_link)` -> `{id, source, options:[{letter,text}], correct, receipt:{heading, lines}, trace: steps (full), home_link}`. `correct` from `bank.correct_index`, `receipt.lines` from `receipt.receipt_lines` (the Python twin of `answers::receipt_lines`, G-7) — refuses (raises `BankError`) a record that renders no receipt, has no derivable correct option, a trace < 2 steps, or (ran) a final step without `stdout` — the same refusals as `answers::load`.
   - `build_html(question, repo_root, *, home_link)` -> one HTML string: CSP meta `default-src 'none'; script-src 'unsafe-inline'; style-src 'unsafe-inline'; font-src data:; img-src data:` (the file itself forbids every request, `connect-src` included — defence in depth for "no network request of any kind"), tokens.css with its `@import url("fonts.css")` replaced by fonts.css whose four `url("fonts/…")` become base64 `data:font/ttf` URIs (D-14), components.css, wall.css, CSS comments stripped; the JS in index.html's order + static.js inline; the bake as `application/json` with `</` escaped.
   - `host_sheet(question)` -> plain text. One block per phase in the room's order, headed by the §11 host phase label (`before the question` … `released`), holding: `work` — each walk step's `Step N of M` and its `note` verbatim; `reveal` — step M's note, then `What happens` + `explains.what`, one entry per incorrect option (`X · option text` + its `why_tempting`, letter order — the room picks the most-chosen one at reveal; with no phones the host picks from a show of hands), `What to remember` + `explains.takeaway`. Other phases: the label only. No other prose; `explains.legacy` and the hint are never included.
   - `write_fallback(question_id, out, *, bank_dir, home_link)` writes `<out>` and `<stem>.host-sheet.txt` beside it in one call; returns both paths — the function T-20 calls.
   - `main(argv)`: `python -m popquiz.fallback <question-id> --out <file> [--home-link URL] [--bank DIR]`; `--bake` prints the bake JSON (fixture regeneration). `--home-link` default `https://popquiz.rustnyc.org/home` (T-09's named host); flagged as a hypothesis until T-09 deploys.
