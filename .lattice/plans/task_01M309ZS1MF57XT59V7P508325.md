## The one rule, and how the design keeps it

Nothing here can change tonight's answer position. The slot path is **its own module**, `popquiz/slot.py`, which imports `hashlib` and `datetime` and nothing else, and holds exactly `_rng` (ported from `build_deck.py:75-84`) and `slot_for_day(day, n_options=5)` (ported from `:162-172`). `audit.py` re-exports `slot_for_day`, so `popquiz.audit.slot_for_day` exists where BUILDPLAN §2 names the module. So "takes the date and nothing else" and "`n_options` is the constant 5" are enforced at the signature, not only asked for (deviation D5).

**AC-26 (bank-audit).** **Statistic:** each tell is a small, fixed family of attendee rules. A rule either names a set S of options for a question or abstains.
- **H** is the rule's hits. **E = Σ|S|/5** is its expected hits if the answer ignored the feature — chance, the blind guess AC-23a also uses. The ratio is **H/E**. This is the precedent in `USER_STORIES.md:373` ("2/8 vs. a 1.6/8 chance baseline").
- Rules that learn from the bank do it **leave-one-out**, so no question predicts itself.
- **FAIL** when a rule's H/E > **1.5** *and* the exact Poisson-binomial tail P(H′ ≥ H) under p_i = |S_i|/5 is ≤ **0.01 / m**, where m is the number of rules in that tell's family.
- **WARN** when H/E > 1.5 but the tail is not that small: reported and printed, exit 0.
- **N/A** when a rule never fires.
- It cannot flake: there is no randomness, and the bank is fixed. It is not vacuous: 4 hits out of 4 on a one-rule tell has p = 0.0016 and fails.

Measured on random banks with no planted tell, the bare 1.5× threshold fails on noise 20–30 % of the time at n = 4–20. That is why the guard exists (deviation D2).

The rules:
- **`unsafe`** (m=1): for a source matching `\bunsafe\b`, S = the options of the kind most common among the *other* `unsafe` questions' answers, or `ub` when there are none (PHILOSOPHY §2's named shortcut).
- **Source length** (m=1): line buckets ≤3 / 4–5 / 6–7 / 8+. S = the options of the bucket's leave-one-out majority answer kind, firing only where it differs from the bank-wide leave-one-out majority, so it measures the feature rather than the base rate.

- **Option text length** (m=2): pick the longest; pick the shortest. Ties take every tied option.
