What this direction is testing

The room votes out loud, option by option. The projector asks for one letter at a time in 150px type; the host counts hands and taps the number. Nobody joins anything.

Stories that evaporate. B1 (join without an account), B5 (capacity, AC-52–55), B7's pre-reveal payload work, and most of B6 — there is no participant client to leak from, no write burst to load-test, and nothing per-person exists to record. The build shrinks to a projector and a host control.

The criterion this direction strains. AC-39 wants anonymous per-option totals at reveal. Hands produce a count only because the host types it, and a hand is visible to the whole room. Direction A is maximally private in the record and maximally public in the moment — the opposite trade from B and C.

AC-91 gets easier, AC-38 gets harder. Everyone reads the same screen at the same instant, so time-to-opinion is one measurement, not fifty. But the projector is now the only place the code exists — if the back row can't read it, there is no fallback.
