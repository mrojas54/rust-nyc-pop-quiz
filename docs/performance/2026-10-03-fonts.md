# Font loading optimization — 2026-10-03

Measured against main `a599e80`. The largest static UI assets were the vendored
TTF fonts. WOFF2 compression preserves the approved families and all glyphs;
no subsetting, font replacement, weight reduction or runtime dependency is used.

| Face | Original bytes | WOFF2 bytes | Reduction |
|---|---:|---:|---:|
| Cascadia Mono upright | 631,788 | 187,276 | 70.4% |
| Cascadia Mono italic | 471,980 | 138,220 | 70.7% |
| Instrument Serif upright | 70,012 | 27,384 | 60.9% |
| Instrument Serif italic | 71,592 | 28,068 | 60.8% |
| All faces | 1,245,372 | 380,948 | 69.4% |

Browsers load only the faces needed on the current surface. A page using the
upright mono and serif faces needs 214,660 font bytes instead of 701,800
(69.4% less). These are file payload measurements, not elapsed load times,
LCP, INP or CLS measurements. No real-device or throttled-network timing claim
is made. Retaining originals increases the embedded server binary's asset size
by 380,948 bytes; supported browsers select WOFF2 first.

The offline fallback embeds only WOFF2, saving 1,152,564 base64 bytes across the
four faces. It retains its no-network CSP and keyboard behavior.
